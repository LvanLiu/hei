# hei

一个 macOS 窗口级切换器：按 `⇧⌘Space` 弹出搜索框，输入即筛，回车切到**那个窗口**。

![面板](docs/design/launcher-dark.png)

## 安装

需要 macOS 13 或更高版本，以及 Xcode 命令行工具。

```bash
cd hei
make build      # 编译出 build/hei.app
make run        # 启动，菜单栏出现图标
```

首次使用要授权：

1. 未授权时启动会自动弹出面板，以及「hei 想要控制这台电脑」。
2. 点「打开系统设置」，在「隐私与安全性 → 辅助功能」里勾选 **hei**。
3. 面板每秒检测一次。开关打开后窗口列表自动出现。

读其他 App 的窗口需要这项权限。

重新编译后，辅助功能里的开关可能还开着，但已经对不上新的程序。先从菜单栏退出 hei，再执行：

```bash
defaults delete com.lvan.hei trustedBuildHash
make run
```

按提示重新勾选 **hei**。

## 使用

| 按键 | 行为 |
|---|---|
| `⇧⌘Space` | 打开 / 关闭切换器 |
| 直接输入 | 按应用名和窗口标题筛选，最佳结果自动选中 |
| `↑` `↓` / `Tab` `⇧Tab` | 移动选择 |
| `↩` | 切到选中窗口。窗口在另一个桌面时，会跟着切过去 |
| `esc` | 关闭，回到原来的 App |
| 鼠标单击某行 | 直接切换 |

不输入时，列表按最近用过的 App、再按窗口前后顺序排列，第一条是上一个活跃窗口。输入 `settings` 或 `设置` 后回车，打开设置。

菜单栏图标 →「设置…」（`⌘,`）：

| 分类 | 内容 |
|---|---|
| 通用 | 开机启动、菜单栏图标、辅助功能权限 |
| 外观 | 跟随系统，或分别选择深色 / 浅色主题 |
| 快捷键 | 唤起快捷键，修改后立即生效 |
| 关于 | 版本、日志（`~/Library/Logs/hei.log`） |

快捷键有四组：`⇧⌘Space`、`⌥Space`、`⌃⌥Space`、`⇧⌘J`。不要用 `⌘Tab`（被 Dock 占用）或 `⌃Space`（输入法切换）。

## 权限与隐私

hei 需要「辅助功能」权限。macOS 没有公开 API 能在不授权的情况下枚举、抬起别的 App 的窗口，所以这个权限是功能前提，不是可选项。

**能读到什么**

- 所有常规 App 的窗口标题、所属 App 名称
- 窗口的位置、大小、是否最小化、在哪个桌面
- 这些数据只用于渲染切换面板，用完即弃，不做持久化

**读不到什么**

- 窗口里的内容：不截图，不申请「屏幕录制」权限
- 你在别的 App 里输入的文字
- 剪贴板、文件系统、浏览器历史

**数据去哪了**

- **不联网。** 整个程序没有任何网络请求代码：无遥测、无崩溃上报、无更新检查、无账号体系。
- 唯一写磁盘的是本地日志 `~/Library/Logs/hei.log`：记录启动、扫描到的窗口数量，以及每次切换的目标窗口标题（便于排查问题）。文件只在你本机，随时可删，删了不影响功能。

**怎么收回**

随时在「系统设置 → 隐私与安全性 → 辅助功能」里关掉开关，hei 会退回只显示授权提示的状态。也可以彻底清空记录：

```bash
tccutil reset Accessibility com.lvan.hei
```

**代码可审计**

全部源码在仓库里，MIT 协议。真正触达窗口数据的是两个文件：

- `Sources/WindowScanner.swift` —— 读取窗口列表
- `Sources/Flipper.swift` —— 抬起 / 激活目标窗口

其余是面板、匹配、主题、设置。想确认「到底有没有联网」，全局搜 `URLSession`、`Network`、`CFNetwork` 即可，一条都搜不到。
